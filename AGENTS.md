# QED-AI public registry instructions

This repository is an unrestricted public catalog. Every field, identifier, URL,
commit, issue, and build output must be safe for public disclosure. Restricted
items may have public metadata records, but those records must not reveal private
SharePoint URLs, internal paths, access-group names, personal information,
security architecture, or confidential filenames.

Prefer stable opaque identifiers, explicit schema versions, enumerated statuses,
and additive changes. Validate registries before committing.
